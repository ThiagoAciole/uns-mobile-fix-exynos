# Histórico da pasta audit

Os relatórios, logs, trechos de assembly, scripts e validações pequenos da análise antiga foram preservados em `naruto-analysis/` e `UltimateNinjaStorm/`.

Em 26/10/2026, os APKs históricos/intermediários e os dados de auditoria descartáveis foram removidos. Os relatórios textuais desta pasta permanecem como registro histórico e não reconstroem os artefatos removidos.
