# assets/

Arte versionada no Git que o projeto usa como referência ou entrada de patch.

Escrito para: quem vai alterar o patch de telas ou procurar a arte original.

| Caminho | Conteúdo | Usado por |
|---|---|---|
| `widescreen-expansion-png/` | Fundo da demonstração da tela de controles (`xoption_battlebg01`), original 1920×1080 e versão widescreen 2342×1080. | Referência da tela de controles. O patch usa esta cópia por padrão. A raiz do projeto mantém o arquivo original `background-joystick-widescreen.png`, com o mesmo SHA-256. Detalhes em [widescreen-expansion-png/README.md](widescreen-expansion-png/README.md). |

Dados extraídos do jogo original (textos, inventários de CPK) não ficam aqui. Eles ficam em `work/inventory/`, que é ignorada pelo Git.
